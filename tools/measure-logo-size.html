Logo size: requested vs drawn

The library rounds the logo to whole QR modules and caps it below the requested fraction, so imageOptions.imageSize does not equal the fraction of the code you get. This page renders the same logo at every value the app's slider can produce and prints the width the library actually draws. Run it after upgrading qr-code-styling.
